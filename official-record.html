Screen Troublemaker

Screen Troublemaker is an original character-driven interactive desktop entertainment experience developed by OLSYD Interactive for Windows PC. The character appears to live on the user's desktop and interact playfully with the screen environment. The project is in development and is currently targeting an initial release in early September 2026.

Game Project

Primal Heist

Primal Heist is an original cooperative prehistoric action-adventure game for 1–4 players developed by OLSYD Interactive for Windows PC. It focuses on teamwork, fast escapes, physical comedy, stylized prehistoric environments and a distinctive cast of animal characters. The project is in development and is currently targeting a February 2027 release window.
